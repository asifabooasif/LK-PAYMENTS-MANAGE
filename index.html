Irreversible actions — proceed with extreme caution

🗑️ Clear All Data

Permanently delete ALL data including suppliers, customers, transactions, cheques, and settings. This cannot be undone.

🔄 Reset All Settings

Reset all settings to factory defaults. Your data (suppliers, customers, transactions) will NOT be affected.

🧪 Clear Cache & Temporary Data

Clear cached data, charts, and temporary files. Your main data is safe.

📦 Rebuild Database

Rebuild internal indexes and optimize data structure. Use if system is slow.

🔑 Reset Security

Remove PIN, clear audit logs, and reset security settings.
